# Antfly Agent Workshop

Read `guides/searchaf-agent/HANDOFF.md` and follow it. Work in a new directory outside this repository. Keys go in private files, never in the starters, the sample folder, or Git. Stop where the handoff says to stop and ask for the instance URL and key.

For app changes, run the app's `npm test`, `npm run typecheck`, and `npm run build`. Preserve lockfiles.
