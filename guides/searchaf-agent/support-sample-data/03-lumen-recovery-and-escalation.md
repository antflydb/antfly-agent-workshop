# Lumen Sync 2.4 — Recovery and support handoff
Fictional workshop documentation. Published September 1, 2026.

The documented self-service recovery window is seven days after a workspace file is removed. Inside that window, open Workspace → Removed files, select the file, and choose Restore.

This document does not establish whether any recovery option exists outside seven days. Do not promise recovery or declare older data permanently lost. Ask a support owner to review the request.

A support handoff should distinguish user-reported symptoms from verified documentation. Include product version, exact error code, source type, approximate failure time, steps already attempted, relevant documentation, and unresolved questions. Do not include passwords, API keys, raw customer records, or unredacted logs. There is no configured support mailbox in this fictional workshop; draft a handoff for manual review. Do not claim a ticket was submitted.
